# Orion Privacy Policy

Effective date: September 22, 2026

## Scope
This policy describes the Orion Roku app and Orion Server, maintained by Raymond Poltera through the rpoltera/Orion GitHub project. Orion is self-hosted software: the Roku app connects to a separately operated Orion Server. If someone else operates your server, that operator controls its accounts, storage, logs, and configuration; contact them about their data practices.

## Information used by Orion
Depending on the features used, Orion processes:
- Connection information, including the server address, authentication tokens, and account or profile information.
- Media information, including file paths, titles, embedded tags, artwork, library metadata, and configured stream sources.
- Playback information, including viewing history, playback progress, and play counts.
- Settings and operational information, including preferences, requests, network addresses visible to the server, error logs, and system diagnostics.

The Roku app stores its server address, authentication token, and certain preferences in local device storage. Orion Server stores library, account, playback, and configuration data on the server and its associated storage.

## How information is used
Information is used to connect and authenticate devices, browse libraries, stream media, resume playback, apply preferences, and operate and troubleshoot the server. Connecting to your own server does not by itself send your media library or viewing history to the Orion project maintainer.

## Third-party services and disclosure
Configured features may contact external services for metadata, artwork, trailers, stream sources, updates, or AI assistance. Those services may receive your network address, requested media identifiers or search terms, and information needed for the selected feature. If you use a remote AI provider for server diagnostics, diagnostic information may be transmitted to that provider. Review the configuration and the provider's privacy policy before using these features.

Server administrators and people with access to its storage, logs, or backups may be able to access stored information. Roku's platform and GitHub's website process information under their own policies. Information you voluntarily submit in a public GitHub issue is public; do not post credentials, tokens, private media paths, or unredacted logs.

## Retention, deletion, and choices
Server data remains until removed by the server operator or affected by the server's retention and backup practices. Disconnecting or removing the Roku app does not delete data held by the server. Ask your server administrator to access, correct, or delete your account and associated records, including any relevant backups. You can stop using Orion or disable optional external integrations through the server's configuration.

## Security
Protect access to your server, devices, credentials, and backups. Connection security depends on your deployment; plain HTTP does not encrypt traffic. No software or network can guarantee complete security.

## Children
Orion does not require a child to register with the project maintainer. Parents and server operators are responsible for managing access, profiles, and appropriate media. Contact the server operator about removal of a child's information stored on their server.

## Changes and contact
Updates will appear on this page with a revised effective date. For project-level privacy questions, use the [Orion project issue tracker](https://github.com/rpoltera/Orion/issues) to request assistance without including personal or confidential information. For data held by a particular server, contact its operator directly.
